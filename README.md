# Routly Node Installer

Instalador público de Routly Node para Ubuntu Server 22.04 LTS o posterior. Este repositorio contiene únicamente el bootstrap y los artefactos compilados de distribución; no contiene el código fuente privado.

## Instalar

    curl -fsSL https://raw.githubusercontent.com/Routly502/routly-node-installer/main/bootstrap.sh | sudo bash
