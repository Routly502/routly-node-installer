- Sustituye la conexión directa de WhatsApp con Meta por AutomatizadoVIP mediante API.
- Configuración en Configuración → APIs: API KEY visible para el administrador y almacenada cifrada, límite de caracteres, pausa entre mensajes, código de país y activación del gateway.
- Envíos con las plantillas de Routly; se conserva el historial de comunicaciones.
- Evita reenvíos automáticos cuando no puede confirmarse si el proveedor aceptó un mensaje.
- Conserva las mejoras fiscales y la conexión de prueba con Digifact de la versión anterior.

IMPORTANTE AL ACTUALIZAR: la conexión anterior con Meta queda desactivada y sus mensajes pendientes se cancelan para no enviarlos mediante otro proveedor. El administrador debe guardar y verificar su API KEY de AutomatizadoVIP y activar el gateway.

Los mensajes aceptados por el proveedor no equivalen a entrega o lectura confirmada. No se modifica correo ni Telegram.

Digifact permite configurar y probar la autenticación; no certifica, transmite ni anula documentos fiscales.

La publicación no inicia actualizaciones automáticamente; cada administrador las inicia desde Routly.
