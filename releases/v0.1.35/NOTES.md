- El perfil del cliente muestra Ver PDF, Editar pago, Eliminar pago y Enviar en las facturas pagadas; ya no ofrece Agregar pago para una factura saldada.
- Si una factura tiene varios abonos, se debe elegir el abono exacto que se editará o eliminará. Los pagos cubiertos solo con saldo a favor no habilitan acciones de efectivo; las facturas pendientes conservan Agregar pago.
